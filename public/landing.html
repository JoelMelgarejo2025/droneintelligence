Flujo de trabajo

Un proceso claro. Del vuelo al análisis.

Un recorrido de referencia para convertir capturas aéreas en productos geoespaciales consultables.

01 / CAPTURA

Adquiere imágenes

02 / PROCESAMIENTO

03 / ANÁLISIS

04 / CONSULTA

Explora resultados

Organiza proyectos, revisa vistas previas y utiliza los productos para el análisis territorial.

Tecnología

Estándares y herramientas del flujo geoespacial.

Integraciones y formatos identificados en el código. Su ejecución requiere que los servicios y dependencias correspondientes estén instalados y configurados.

GeoTIFFEntrada de ortomosaicos RGB georreferenciados.
YOLODetección de objetos mediante modelos locales compatibles.
NodeODMEnvío y seguimiento de tareas fotogramétricas.
Python · GISProcesamiento raster, reproyección y generación de teselas.

Nota de disponibilidad: el sitio estático puede mostrar la landing y los recursos visuales. Las operaciones de procesamiento requieren un backend desplegado, seguro y conectado; no se asume que los servicios locales estén activos en este dominio.

Preguntas frecuentes

Lo esencial antes de comenzar.

Es una plataforma geoespacial orientada a visualizar y trabajar con imágenes de drones, ortomosaicos y productos raster para apoyar el análisis territorial.
El flujo de ortomosaicos del backend contempla GeoTIFF RGB con sistema de referencia espacial. Otros productos requieren flujos específicos.
El código incluye una ruta de detección. Para ejecutarla se necesita instalar Ultralytics y disponer de un modelo .pt en el entorno de ejecución.
El backend contempla el envío de fotografías a NodeODM, el seguimiento de tareas y la descarga del ortomosaico. Requiere un servicio NodeODM accesible desde el servidor.
La landing es contenido estático. El procesamiento y las funciones que dependen de Python, YOLO o NodeODM necesitan un backend de producción con autenticación, almacenamiento persistente y configuración segura. No se deben cargar datos privados hasta que ese servicio esté habilitado.
